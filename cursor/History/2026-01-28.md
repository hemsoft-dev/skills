### 1. Added New "Context Inclusion with @ Symbol" Section

**Content Added:**

- Complete table of all `@` options:
  - `@Files` - Include specific files
  - `@Folders` - Include entire folders
  - `@Code` - Reference symbols (functions, classes, variables)
  - `@Docs` - Include documentation/web results
  - `@Web` - Web search and include results
  - `@Git` - Include git diff/changes
  - `@Codebase` - Semantic search across project
  - `@Chat` - Reference previous chat messages

**Usage Examples:**

```

"Explain how @fetchUser function works with @database/"
"Update @codebase error handling to match @docs error boundaries"
```

**Tips:**

- Can combine multiple `@` references
- Explicit control vs auto-included files

# Desktop Backgrounds Resources

## Overview

This document catalogs high-quality, free desktop backgrounds from vetted sources, organized by category and Windows compatibility. All links are to materials available under CC0 or open-source licenses with no attribution required, no watermarks, and no paywalls.

**Windows Compatibility**: All recommended resolutions are standard: **1920x1080**, **2560x1440**, **3840x2160** (4K)

## Recommended Workflow

### To Add Backgrounds to Assets Folder

1. **From Wallhaven or Stock Sites**:
   - Download specific images
   - Verify Windows resolution (1920x1080 minimum)
   - Save to appropriate `assets/` category folder

2. **From GitHub Repositories**:
   - Clone repo to temp location
   - `Move-Item` PNG/JPG files to `assets/` folders
   - Organize by aesthetic (minimalist → Minimalist/, etc.)

3. **Bulk Downloading**:
   - Use browser developer tools or download managers for collections
   - Always respect each source's ToS (all listed here permit bulk downloads)
   - Verify CC0/MIT licensing before bulk use

### Pro Tips

- **Unsplash/Pexels/Pixabay**: Most direct download buttons, good for 1-2 images
- **Wallhaven**: Best for browsing + filtering specific aesthetics
- **GitHub repos**: Best for complete themed collections (clone once, use forever)
- **Windows compatibility**: Download at native resolution or 16:9 aspect ratio minimum

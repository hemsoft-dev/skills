## 16:27 - Retrospective: normalize-account.ps1 Issues Identified

**Issues Discovered:**

1. PowerShell syntax error: $InformationPreference was placed before param() block (must come after)
2. Hardcoded drive path: F:\OneDrive instead of D:\OneDrive
3. Compatibility issue: Get-Content -Raw parameter failed in user's PowerShell version
4. Year hardcoding: Script only processes 2025 folder, won't work for 2026+

**Root Cause:**
Script likely created on a different system with different PowerShell version and drive configuration. No dynamic year detection.

**Resolution Applied:**

- Moved $InformationPreference after param() block
- Changed path from F:\ to D:\
- Replaced Get-Content -Raw with array join

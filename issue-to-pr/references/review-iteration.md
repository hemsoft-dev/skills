# Review iteration

Before requesting or waiting for external review, read
`../../process-pr/references/pr-reviewer-policy.md`. That file owns the product
registry, reviewer selection, requester identity, triggers, refusals, and wait
limits for every PR workflow.

Use `../../process-pr/references/current-head-review-loop.md` for baseline
queries, paginated thread evidence, finding decisions, and final readiness.

1. Bind the review request and result to the current PR head SHA.
2. Reuse existing requests, including those made by a composing workflow.
3. Assess findings from every source; fix or disprove each actionable finding.
4. Validate and push changes, then obtain fresh evidence for the new head.
5. Resolve addressed threads only when permitted by the repository contract.
6. Re-fetch required reviews, checks, and findings before declaring readiness.

Do not duplicate the product list or request procedures in this reference.

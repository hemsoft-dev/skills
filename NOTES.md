# Teaching notes

- Franz already understands skills and MCP servers. Do not spend lessons on plugin packaging unless a later extension needs distribution.
- The interesting part is executable, stateful participation in a live Copilot CLI session and how that compares with Canvas extensions.
- Favor a working extension over a broad SDK tour.
- Use Windows and PowerShell commands.
- Re-check official documentation and the installed CLI before each hands-on lesson because extensions are experimental.

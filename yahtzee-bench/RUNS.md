# Yahtzee-Bench — Run Log

One row per Create run. This file lives in the skill folder only — never copy it into the entries repo.

**Rules**

- Add a row at the start of every run (Status: `Running`), then update the same row when the run ends.
- Time taken = total elapsed time for the run (e.g. `11m 34s`), platform-reported if available.
- Cost = actual spend for the run if the platform reports it (USD); otherwise `unknown` — the owner can fill it in later.
- Never modify another run's row, except to fill in `Cost` when the owner provides it.

# AI Certification Tracker

Track progress toward two Azure AI certifications in sequence.

## Links Rule

**ALWAYS include clickable links** in every response. When mentioning any module, learning path, documentation page, or resource, provide the direct Microsoft Learn URL. The user must never have to search for material — every reference must be one click away.

- Module names → link to the module page
- Topics → link to the relevant documentation
- Study guides → link to the study guide page
- Practice assessments → link to the assessment page
- When suggesting supplementary material, include the URL

## Default Behavior

When activated without a command, show `status` — a dashboard of current certification progress including which week you're in, what's due, and completion percentage. Include clickable links to the next modules the user should work on.

## Commands

| Command | Action |
|---------|--------|
| `status` | Show current week, progress %, upcoming tasks, and deadlines |
| `plan` | Show the full study plan for both certifications |
| `log` | Record a study session (topic, duration, notes) |
| `review` | Generate a readiness assessment for the current exam |

### AI-103 Detailed Skill Objectives

**Plan and manage an Azure AI solution (20–25%):**

- Select the appropriate Microsoft Foundry Services
- Plan, create, and deploy a Microsoft Foundry Service
- Manage, monitor, and secure a Microsoft Foundry Service
- Implement AI solutions responsibly (content moderation, content safety, prompt shields)

**Implement generative AI solutions (15–20%):**

- Build generative AI solutions with Microsoft Foundry
- Use Azure OpenAI in Foundry Models to generate content
- Optimize and operationalize a generative AI solution

**Implement an agentic solution (5–10%):**

- Create custom agents (Microsoft Foundry Agent Service, Microsoft Agent Framework)
- Multi-agent orchestration and autonomous capabilities

**Implement computer vision solutions (10–15%):**

- Analyze images (object detection, tags, OCR, handwriting)
- Implement custom vision models
- Analyze videos (Video Indexer, Spatial Analysis)

**Implement natural language processing solutions (15–20%):**

- Analyze and translate text (key phrases, entities, sentiment, PII, translation)
- Process and translate speech (TTS, STT, SSML, custom speech)
- Implement custom language models (intents, entities, Q&A, multi-turn)

**Implement knowledge mining and information extraction (15–20%):**

- Implement Azure AI Search (indexes, skillsets, indexers, semantic/vector search)
- Implement Azure Document Intelligence
- Extract information with Azure Content Understanding

```markdown
### {date} — {topic}

- **Modules completed**: {list}
- **Notes**: {user notes}

```

## Review Command

When `review` is called, generate a readiness assessment:

1. Calculate % of learning paths completed
2. Check if practice assessment has been taken
3. Identify weak domains (by weight vs study time)
4. Provide go/no-go recommendation
5. Suggest focused review topics **with direct links to relevant modules and documentation**

For each weak area, include:

- Link to the specific learning module that covers it
- Link to the relevant Azure documentation page
- Link to the practice assessment

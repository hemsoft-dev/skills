# History: 2026-01-27

## 23:58 - Documented Installation and Update Methods

**Context:** User asked about managing Gemini CLI with Scoop as a package manager, similar to Bun. Investigation revealed important differences in distribution and update methods.

**Current State Discovered:**

- User on v0.25.2 (behind - v0.27.0-preview.0 is latest)
- Installed via npm at `%APPDATA%\npm\gemini`
- Gemini CLI is NOT available in Scoop (checked via `scoop search gemini-cli`)

**Key Findings:**

1. **Official Distribution: npm Only**
   - Google publishes `@google/gemini-cli` to npm registry
   - No official Windows package manager support (no Scoop, no Chocolatey)
   - Requires Node.js as dependency

2. **Why npm is Best (and only option):**
   - Official channel maintained by Google
   - Fast updates when new versions release
   - Already working and established
   - No alternative exists

3. **Update Commands:**

   ```powershell
   # Standard update
   npm update -g @google/gemini-cli
   
   # Force latest
   npm install -g @google/gemini-cli@latest
   
   # Preview releases
   npm install -g @google/gemini-cli@latest --tag next
   ```

**Skill Updates (V1.2 → V1.3):**

1. **Added "Installation" section:**
   - Official npm installation command

2. **Added "Updating Gemini CLI" section:**
   - Version check commands

   - Link to GitHub releases

3. **Why This Matters:**
   - Clarifies there's no native updater (unlike Bun's `bun upgrade`)
   - Prevents users from searching for Scoop packages
   - Documents the ONLY official update method
   - Sets expectations: manual npm updates required

**Comparison to Other CLIs:**

| CLI Tool | Updater | Distribution | Best Method |
|----------|---------|--------------|-------------|
| Bun | ✅ Native (`bun upgrade`) | Binary + Scoop | Native updater |
| Goose | ⚠️ Requires WSL | Binary (GitHub) | Manual download |
| Gemini CLI | ❌ None | npm only | `npm update -g` |
| GitHub CLI | ✅ Native (`gh upgrade`) | Binary + Scoop + winget | Native updater |

**Takeaway:** Gemini CLI follows the npm ecosystem pattern (like TypeScript, ESLint, etc.) rather than the native binary pattern (like Bun, gh, etc.). This means standard npm update workflows apply.

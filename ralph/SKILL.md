# Ralph Loops

Expert in the Ralph Loops autonomous automation system located at `D:\github\Relias\ai-tools\ralph-loops\`.

## Core Scripts

| Command | Script | Purpose |
|---------|--------|---------|
| `ralph` | `ralph.ps1` | Iterative autopilot dev loop with worktrees, PR creation, and handoff |
| `ralph-pr` | `ralph-pr.ps1` | PR monitoring — fixes CI failures and review comments automatically |
| `ralph-issues` | `ralph-issues.ps1` | Read-only codebase scanner that creates GitHub Issues |
| `ralph-audio` | `ralph-audio.ps1` | Toggle audio on/off globally (takes effect mid-run) |
| `ralph-run-all` | `scripts/ralph-run-all.ps1` | Sequential orchestrator — runs all improvement scripts in autopilot |

## Audio System

Audio uses dynamic TTS via `edge-tts` (generates contextual spoken messages on the fly, plays with `ffplay`, deletes temp files). The shared module is `lib/audio.ps1` with `Speak-Status` and `Format-SpokenDuration`.

### Toggle Audio

```powershell
ralph-audio         # show current state
ralph-audio -Off    # mute all loops immediately (even mid-run)
ralph-audio -On     # re-enable audio
```

The kill switch lives in `config/settings.json` → `audio.enabled`. It is re-read on every `Speak-Status` call so changes take effect without restarting.

Per-script override: pass `-NoAudio` to any ralph script to suppress audio for that run only.

### Repo Audio Identifier

Each repo needs an MP3 identifier at `<repo>/assets/ralph-loop/<repo-name>.mp3`. Auto-generated by `edge-tts` on first run if missing, or via `ralph -Install`.

## Loop Limits (Guardrails)

The PR fix loop (`ralph-pr.ps1`) enforces two limits — whichever is hit first stops the loop gracefully, leaving the PR as-is:

| Limit | Default | Override |
|-------|---------|----------|
| **MaxHours** | 4 | `-MaxHours 6` or `config/settings.json` → `limits.maxHours` |
| **MaxRounds** | 10 | `-MaxRounds 20` or `config/settings.json` → `limits.maxRounds` |

**Resolution priority**: explicit `-MaxHours`/`-MaxRounds` param → `config/settings.json` → hardcoded default.

When a limit is hit, the script announces via TTS, logs the reason, and exits. The PR is left in its current state (no forced merge, no forced close).

`ralph.ps1` passes these through to `ralph-pr.ps1` during handoff if specified.

## Installing Scripts Into a Repo

Run from the consumer repo root:

```powershell
ralph -Install             # interactive (prompts per existing file)
ralph -Install -All        # install all, skip existing
ralph -Install -Force      # overwrite existing
ralph -Install -Pick       # choose which scripts
```

This copies template scripts to `<repo>/scripts/` and generates the repo audio identifier.

## Key Parameters

### `ralph` (dev loop)

| Param | Purpose |
|-------|---------|
| `-Max N` | Iteration count (default 10) |
| `-Prompt <file\|text>` | Work prompt (default: prompt.md or built-in) |
| `-Branch <name>` | Target branch (auto-generated if omitted) |
| `-Issue <number>` | Work from a GitHub Issue |
| `-WorkUntil HH:mm` | Time deadline |
| `-MaxHours N` | Max hours for PR phase (default: 4, from config) |
| `-MaxRounds N` | Max fix rounds for PR phase (default: 10, from config) |
| `-Model <alias>` | Model: `sonnet`, `opus46`, `opus47`, `gpt` |
| `-Provider <name>` | CLI provider: `copilot`, `opencode` |
| `-Agents <specs>` | Agent roles (comma-separated) |
| `-Once` | Single iteration |
| `-NoPR` | Skip PR creation/handoff |
| `-Autopilot` | Fully unattended (auto-merge) |
| `-CleanupWorktree` | Remove worktree after |

### `ralph-pr` (PR fix loop)

| Param | Purpose |
|-------|---------|
| `-PRNumber N` | PR to monitor (interactive if omitted) |
| `-MaxIdleCycles N` | Idle cycles before exit (default 3) |
| `-WaitMinutes N` | Pause between checks (default 3) |
| `-MaxHours N` | Max hours before stopping (default: 4, from config) |
| `-MaxRounds N` | Max fix rounds before stopping (default: 10, from config) |
| `-Agents <specs>` | Review agent roles |
| `-SkipReview` | Don't request Copilot review |
| `-Autopilot` | Auto-merge when clean |

### `ralph-issues` (issue scanner)

| Param | Purpose |
|-------|---------|
| `-Max N` | Scan iterations (default 5) |
| `-Labels <list>` | Labels to apply |
| `-DryRun` | Report only, don't create |

## Configuration

All config lives in `ralph-loops/config/`:

| File | Purpose |
|------|---------|
| `settings.json` | Runtime switches (audio, loop limits) |
| `models.json` | Model definitions, aliases, tiers, cost multipliers |
| `agents.json` | Agent role definitions (dev and review categories) |
| `providers.json` | CLI provider mappings (copilot, opencode, etc.) |

Shared libraries in `ralph-loops/lib/`:

| File | Exports |
|------|---------|
| `config.ps1` | Model/agent/provider resolution, command building |
| `audio.ps1` | `Speak-Status`, `Format-SpokenDuration`, `Test-AudioEnabled` |

## Worktree Convention

```
D:\github\Relias\my-repo\                    ← main working tree
D:\github\Relias\my-repo.worktrees\
    feature-my-branch\                        ← worktree (slashes → hyphens)
```

## Logging

- `ralph.log` — written in the invocation directory
- `ralph-pr.log` — written in the invocation directory
- `ralph-summary.log` — one-line-per-run summaries in the ralph-loops directory

## Prerequisites

- GitHub Copilot CLI (`copilot` on PATH)
- GitHub CLI (`gh`, authenticated)
- PowerShell 7+
- Git 2.15+
- edge-tts (`pip install edge-tts`) for audio
- FFmpeg (`ffplay` on PATH) for audio playback

All scripts use `# Version: X.Y.Z` in line 2. Config files use `"version": "X.Y.Z"`. Follow SemVer: patch for fixes, minor for features, major for breaking changes.

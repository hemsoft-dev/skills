#### `Test-SoftwareWatchlist.ps1`

**Usage:**

```powershell

```

#### `Get-SoftwareUpdates.ps1`

- Actively checks for software updates
- Supports filtering by check method (github_releases, web, cli)
- Reports found updates with old/new version comparison
- Exits with error code if zero updates found (when checking all)
- Provides detailed error reporting

**Usage:**

```powershell
# Check all software
.\Get-SoftwareUpdates.ps1

# Check only GitHub releases
.\Get-SoftwareUpdates.ps1 -Method github_releases

# Check and update tracking (not yet implemented)
.\Get-SoftwareUpdates.ps1 -UpdateTracking
```

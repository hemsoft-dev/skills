## 🎯 Today's Highlight

**[GitHub Releases Copilot-SDK to Embed Its Agentic Runtime in Any App](https://marktechpost.com/2026/01/23/github-releases-copilot-sdk-to-embed-its-agentic-runtime-in-any-app)**

GitHub released the Copilot SDK in technical preview, providing programmatic access to the agentic runtime that powers GitHub Copilot CLI. The multi-platform SDK (Node.js/TypeScript, Python, Go, .NET) allows developers to embed the same agent execution loop into their own applications, enabling multi-turn conversations, custom tool execution, and full lifecycle control without building custom planner and tool loops from scratch.

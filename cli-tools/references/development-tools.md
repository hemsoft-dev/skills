## prs - Pull Request Checker

| Field | Value |
|---|---|
| Author | HemSoft Developments (Franz Hemmer) |
| Current version | 0.1.5, verified 2026-01-19 |
| Purpose | Check pull-request status across GitHub and Bitbucket repositories. |

### Commands

```powershell
# Install
npm install --global @hemsoft/prs

# Update
npm update --global @hemsoft/prs

# Check installed and latest versions
prs --version
npm view @hemsoft/prs version
```

### Links

- npm: <https://www.npmjs.com/package/@hemsoft/prs>
- GitHub: <https://github.com/HemSoft/prs>

### Usage

Run `prs` to check pull-request status across both supported providers.

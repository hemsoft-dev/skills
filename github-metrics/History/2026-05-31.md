## 20:10 - June Billing Transition API Check

Researched whether GitHub Copilot billing APIs have been updated now that the June 1, 2026 usage-based billing period is live (UTC). Key findings below.

### Confirmed: What HAS changed

| Finding | Detail |
| --- | --- |
| **Usage-based billing is officially live** | June 1, 2026 UTC — PRUs are replaced by AI Credits |
| **Copilot Max plan added** | $100/month individual plan with 20,000 credits (10,000 base + 10,000 flex) |
| **Base + Flex allotment model** | Individual plans now split credits into "base" (matches subscription price) + "flex" (variable adaptation buffer). Pro=$1,500 total, Pro+=$7,000 total, Max=$20,000 total |
| **Enterprise-level `usage/summary` endpoint confirmed** | `GET /enterprises/{enterprise}/settings/billing/usage/summary` — public preview, filterable by org, repo, product, sku, cost_center_id |
| **Model pricing catalog expanded** | New models: GPT-5.4 nano ($0.20/$1.25), Claude Opus 4.7/4.8, Gemini 3.5 Flash, Gemini 3.1 Pro, GitHub Raptor mini |
| **10% auto-model discount** | Users get 10% off token costs when using auto model selection in Chat, CLI, or cloud agent |
| **Pool mechanics clarified** | Adding licenses mid-cycle increases pool immediately; removing doesn't shrink until next cycle |
| **Code review double-billing confirmed** | Consumes AI Credits (for inference) AND GitHub Actions minutes (for agentic infrastructure) |
| **Budget hierarchy** | User-level → Cost-center → Enterprise spending limit → Org-level budgets |
| **Promotional credits confirmed** | Jun–Aug 2026: Business 3,000/user/mo, Enterprise 7,000/user/mo (matches skill V1.3) |

### Confirmed: What has NOT changed in the API

| Surface | Status |
| --- | --- |
| `GET /enterprises/{enterprise}/settings/billing/premium_request/usage` | Still live, same response schema (grossQuantity, netQuantity, grossAmount, netAmount) |
| `GET /enterprises/{enterprise}/settings/billing/usage` | Still live, same schema |
| `GET /enterprises/{enterprise}/settings/billing/usage/summary` | Still public preview |
| `GET /orgs/{org}/settings/billing/budgets` | Still live |
| API version header | Still `X-GitHub-Api-Version: 2026-03-10` |
| No new `/ai_credits/usage` endpoint | The billing is tracked through the *existing* `premium_request/usage` and `billing/usage` endpoints — no dedicated new "AI Credits" API surface found |

### Conclusion

The `premium_request/usage` endpoint is still the correct surface for model-level AI Credit billing. The SKU, unitType, and pricePerUnit fields changed to reflect the new billing model. The `usage/summary` endpoint provides the aggregate view (no model breakdown). Both work for June. Skill documentation needs a minor update to reflect the new field values.

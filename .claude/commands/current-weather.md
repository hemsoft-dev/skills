# Goal

Provide detailed weather report to the user using the weather skill.

## Parameters

- `zip or city` - Optional.

## Instructions

<!-- markdownlint-disable MD013 -->
Make sure to follow the skill instruction closely unless the user overrides with a different location. If so only focus on that location and try to find equally the same amount of data for that location including power outages, airport situation, etc.
<!-- markdownlint-enable MD013 -->

## Report

Always report back as much detail as you can and always provide links when possible.

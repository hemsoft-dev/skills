# Goal

To have a diary entry in the entries folder in the format of YYYY-MM-DD.md

## Variables

- `Current date` - Automatically determined from system date (no user input required)

## Parameters

This command takes no parameters. It automatically uses today's date to create the diary entry.

## Instructions

Use the diary skill to scaffold out today's diary entry. Use the Slack skill to populate the Slack section and use the today skill to populate the news section. Use the todoist skill to look at my tasks for today but do not include any regular chore type tasks in the diary as they add no value.

## Report

Report back what you did and the remaining tasks to be completed by asking the user for additional information.

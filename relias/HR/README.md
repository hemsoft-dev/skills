# HR Documents

This folder contains Relias HR-related documents converted to Markdown format using docling.

## Document Conversion Process

All documents in this folder have been converted from PDF/DOCX to Markdown using:

```bash
docling {original-file} --to markdown --output HR/
```

## Organization

- Documents are stored with descriptive filenames
- When updating, include date in filename (e.g., `policy-name-2026-01.md`)
- Outdated versions moved to `archive/` subfolder when replaced

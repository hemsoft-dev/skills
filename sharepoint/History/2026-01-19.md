## 16:10 - Fixed Authentication: Added -PersistLogin Parameter

**Research Finding:** PnP PowerShell v3.0+ requires `-PersistLogin` parameter for token persistence. Without it, tokens are NOT cached between sessions.

**Changes Made:**

1. Updated all scripts to use `-PersistLogin` parameter:
   - Get-AIChapterDocuments.ps1
   - Get-AIChapterFolders.ps1
   - Get-AIFoundationChapter.ps1
   - Test-SharePointConnection.ps1
2. Updated SKILL.md with correct token cache location: `%LOCALAPPDATA%\.m365pnppowershell` (not Azure.Identity cache)
3. Documented that `-PersistLogin` is REQUIRED for token persistence
4. Added troubleshooting steps for repeated authentication

**Key Takeaway:** PnP PowerShell v3.0+ token caching REQUIRES `-PersistLogin` parameter. Token cache location is `%LOCALAPPDATA%\.m365pnppowershell`, not Azure.Identity cache. First connection with `-PersistLogin` will prompt for auth, subsequent connections will reuse cached token automatically.

# Notes Organization

This folder contains all personal notes organized by category.

## Folder Structure

- **Projects/** - Project-specific notes and documentation
- **Ideas/** - Random ideas, thoughts, and brainstorming
- **References/** - Reference materials, documentation, guides
- **Personal/** - Personal notes and reflections
- **Work/** - Work-related notes and documentation
- **Archive/** - Older notes moved here for organization

## Migration Notes

Notes are gradually being migrated from other locations to this structure. When adding notes:

1. Determine the appropriate category
2. Place the note in the correct subfolder
3. Use descriptive filenames (e.g., `2026-01-28-meeting-notes.md`)

## 19:58 - Add deterministic repository scoring

Added an 18-concern score sheet with fixed evidence dimensions, applicability rules, `N/A` handling, ranking, evidence coverage, and a report-only `score` invocation. Retrospective found that blocked evidence must remain separate from both failures and genuinely inapplicable concerns to prevent inflated or misleading scores.

## 20:09 - Require one HTML audit report

Required every audit mode to write a self-contained report at `audit/audit-score.html`, added atomic-write and validation rules, and limited score-only HTML to the score sheet and applicability notes.

## 20:41 - Require stack-specific lint and analyzer evidence

Made compiler, type, lint, format, framework, and Markdown checks distinct required rows. React audits now preserve React Doctor's native score and scope; .NET, Go, and Rust audits record their language-specific analyzer configuration, suppressions, and enforcement without blending tool scores into the repository score.

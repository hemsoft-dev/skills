GitHub Actions Workflow (.github/workflows/*.yml)

Railroad diagram for the YAML schema of GitHub Actions workflow files

Source: https://docs.github.com/en/actions/writing-workflows/workflow-syntax-for-github-actions

Workflow File

Top-level structure of a GitHub Actions workflow YAML file

Trigger Events

Events that trigger the workflow (on:)

Single Event

A single event name as a string

Event Name

Supported trigger event names

Event Config Map

Map of event names to their filter configurations

Event Filters

Filter configuration — varies by event type (push/PR: branches/tags/paths; workflow_dispatch: inputs; workflow_call: inputs/outputs/secrets; others: types)

workflow_call Config

Reusable workflow trigger configuration (inputs, outputs, secrets)

workflow_call Output

A single output exposed by a reusable workflow

workflow_call Secrets

Secrets configuration for reusable workflows

workflow_dispatch Inputs

Manual trigger input parameters

Input Definition

A single workflow_dispatch input parameter

schedule

Cron-based schedule triggers

Permissions

Workflow or job-level GITHUB_TOKEN permissions

Permission Map

Granular permission scopes

Env Map

Environment variables as key-value pairs

Defaults

Default settings for all run steps

Shell

Shell to use for run steps

Concurrency

Concurrency control to prevent simultaneous runs

Jobs Map

Map of job IDs to job definitions

Job Definition

A single job's configuration

Needs

Job dependencies — jobs that must complete before this one

Runner

The runner environment for the job

Runner Label

Common GitHub-hosted runner labels

Environment

Deployment environment with optional protection rules

Job Outputs

Outputs from a job that can be used by dependent jobs

Strategy

Matrix strategy for running a job with multiple configurations

Matrix

Matrix configuration with dimensions, includes, and excludes

Matrix Modifier List

Array of matrix combination overrides

Container

Docker container to run the job in

Credentials

Docker registry authentication

Services Map

Service containers for the job (e.g., databases)

Steps

Ordered list of steps to execute in the job

Step

A single step — either an action (uses) or a shell command (run)

Action Step (uses)

Runs a reusable action from the marketplace or a local path

Action Reference

Reference to a GitHub Action

With Map

Input parameters for the action

Run Step (run)

Executes a shell command or script

Reusable Workflow Ref

Reference to a reusable workflow (workflow_call)

Expression

GitHub Actions expression syntax ${{ ... }}

Context Reference

Available expression contexts

Function Call

Built-in expression functions

Comparison

Comparison operations in expressions

Logical Operation

Logical operations in expressions

String List

YAML array of strings

Value List

YAML array of mixed values

Port List

Container port mappings

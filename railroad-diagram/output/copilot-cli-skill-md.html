GitHub Copilot CLI — SKILL.md Frontmatter

Railroad diagram for the YAML frontmatter schema of agent skills (SKILL.md) per GitHub Copilot CLI documentation (docs.github.com)

Source: https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/create-skills

SKILL.md File

Complete structure of a SKILL.md agent skill file

Frontmatter

Required and optional YAML fields

Allowed-Tools Field

Space-separated list of pre-approved tools (WARNING: shell/bash bypass confirmation)

Tool Spec

A single tool permission: simple name or qualified pattern

Hooks Block

Lifecycle hooks — PostToolUse runs after tool calls; Stop runs before session ends

Hook Entry List

One or more hook entries, each with a matcher and hook steps

Hook Entry

A single hook entry: matcher pattern + list of hook steps

Hook Step List

One or more hook steps to execute

Hook Step

A single hook action — prompt injection or command execution

Markdown Body

Free-form Markdown instructions, examples, and guidelines for the agent

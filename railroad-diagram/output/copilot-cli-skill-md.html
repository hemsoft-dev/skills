GitHub Copilot — SKILL.md Frontmatter

Railroad diagram for the YAML frontmatter schema of agent skills (SKILL.md) per agentskills.io specification and GitHub Copilot documentation. Covers Cloud Agent, CLI, and VS Code agent mode.

SKILL.md File

Complete structure of a SKILL.md agent skill file

Frontmatter

Required and optional YAML fields per agentskills.io spec

Allowed-Tools Field

Space-separated list of pre-approved tools (WARNING: shell/bash bypass confirmation)

Metadata Block

Arbitrary key-value mapping for additional metadata (clients use this for non-spec properties)

Tool Spec

A single tool permission: simple name or qualified pattern

Markdown Body

Free-form Markdown instructions, examples, and guidelines for the agent

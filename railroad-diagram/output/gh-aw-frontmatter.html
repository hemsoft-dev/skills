GitHub Agentic Workflows (.md) Frontmatter

Railroad diagram for the YAML frontmatter schema of gh-aw workflow markdown files

Source: https://github.github.com/gh-aw/reference/frontmatter/

Workflow File

Complete structure of a gh-aw workflow .md file

Frontmatter

Top-level YAML fields (on: is required, all others optional)

Trigger Events

on: section — when the workflow should run

Trigger Block

Full YAML trigger configuration with optional enhancements

Trigger Type

Primary trigger event (one or more)

Trigger Shorthand

Natural-language shorthand strings (auto-include workflow_dispatch)

Fuzzy Schedule

Human-friendly schedule expressions (compiler scatters execution time)

Time Constraint

Optional time window for fuzzy schedules

Trigger Enhancements

Additional on: fields that modify trigger behavior

Skip-If Config

Shorthand string or object with query, max/min, scope

Permissions

GitHub token read permissions for the agent job

Engine Config

AI engine selection and configuration

Tools Config

Tools available to the AI agent

MCP Server Defs

Custom MCP server configuration (one or more named servers)

Network Config

Control outbound network access via AWF firewall

Firewall Options

Advanced firewall configuration

Safe Outputs

Validated GitHub operations — agents run read-only, separate jobs execute requests

Global Safe-Output Options

Options that apply to all safe outputs

Issue & Discussion Outputs

Safe outputs for issues, discussions, and their lifecycle

Create-Issue Fields

Fields for create-issue safe output

Comment & Label Outputs

Safe outputs for comments, labels, reviewers, assignments

Pull Request Outputs

Safe outputs for PR creation, updates, reviews

Project & Release Outputs

Safe outputs for projects, releases, assets, code scanning

Orchestration Outputs

Safe outputs for workflow dispatch, workflow call, agent sessions

Cross-Repo Fields

Fields available on most safe outputs for cross-repository operations

Run & Misc Fields

Run configuration and miscellaneous top-level fields

Markdown Instructions

The agent prompt body — plain markdown after the closing ---

Issue Event Types

Activity types for issues trigger

PR Event Types

Activity types for pull_request trigger

Comment Event Types

Activity types for issue_comment, pull_request_review_comment, and discussion_comment triggers

Input Defs

workflow_dispatch input parameter definitions

Cron Expression

Standard cron syntax with optional timezone

App Credentials

GitHub App authentication credentials

Pre-Activation Steps

Custom steps that run before the agent (outside firewall sandbox)

GitHub Tool Config

Configuration for the built-in GitHub tool

Message Templates

Custom notification message templates for safe outputs

Update Fields (status/title/body)

Fields available on update-issue safe output

Close Fields

Fields for close-issue/close-pull-request safe outputs

Custom Steps

Steps that run before the agent job in the workflow

Post Steps

Steps that run after the agent job completes

Custom Jobs

Additional workflow jobs alongside the agent job

Import List

Import shared workflows or configurations

Runtime Overrides

Override default runtime versions for language runtimes

Cache Config

Cache configuration for dependencies

Checkout Config

Extended checkout configuration for cross-repo workflows

Quick reference

Copilot extension boundaries

Choose by runtime behavior, not by GitHub's overloaded names.

Mechanism What it is Use it when Key limit
Plugin An installable bundle of agents, skills, hooks, MCP, and LSP configuration. You need distribution, versioning, or shared defaults. Packaging alone adds no runtime model beyond its bundled parts.
CLI extension A long-lived Node.js process that joins a CLI session through @github/copilot-sdk/extension. You need event observation, session state, custom tools, slash commands, or terminal forms. The API is experimental. The documented UI is host-provided elicitation, not a free-form app panel.
Canvas extension A shared interactive artifact shown in the Copilot app's right-side panel. People and agents need to edit the same visual state through controls and agent-callable capabilities. It requires the Copilot app Canvas host.
Fast test. If the requirement begins with "while this session runs," try a CLI extension. If it begins with "show a shared board, document, or dashboard," try a Canvas extension. If it begins with "install this configuration everywhere," use a plugin.

Locations

User CLI extension ~/.copilot/extensions/NAME/extension.mjs
Project CLI extension .github/extensions/NAME/extension.mjs
User Canvas extension ~/.copilot/extensions/NAME/
Project Canvas extension .github/extensions/NAME/

The overlapping paths are intentional. The active Copilot host determines which capabilities and interface are available.
